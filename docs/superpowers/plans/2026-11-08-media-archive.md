# 媒体时间归档与递归扫描

已确认：递归发现媒体，统一归档到年/年月，日期不可靠时进入日期待确认；用户确认才移动，不覆盖、不删空目录，可撤销。

1. 先增加路径规则、嵌套扫描与移动/撤销测试，并验证失败。
2. 共用路径规则改为年/年月；非可靠日期进入日期待确认，手动年月优先。
3. Organizer 递归扫描媒体，跳过隐藏、符号链接、图库和归档目录；记录来源相对路径与源目录身份。含媒体的直属文件夹不再作为普通项目建议。
4. 扩展日志源目录验证，兼容旧日志；保留冲突与回滚机制。
5. 精简页面为年月编辑和日期状态，同步文档及受影响测试。
6. 运行 npm run check、npm test、npm run test:e2e。
