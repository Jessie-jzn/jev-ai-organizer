# 文件类型归档与空源目录清理

用户已批准：直属普通文件按类型给建议；普通文件不从子目录提取，文件夹不整体移动；媒体递归提取到照片视频/年/年月或日期待确认。移动需要确认。只清理由成功移动媒体造成的空目录，保留根目录和含隐藏文件的目录；撤销恢复源目录。

1. 增加文件类型建议、媒体顶层路径、空目录清理/撤销/重启和替换保护的失败测试。
2. 增加独立类型规则。HTTP 扫描使用保留文件夹的扫描范围，兼容 Organizer 原有显式文件夹操作及旧日志；自定义收件箱体系优先。
3. 媒体共享路径增加照片视频前缀；跳过既有归档。
4. 在所有成员移动完成后，按深度清理空源目录。每次删除前写日志，使用 rmdir 而非递归删除，记录身份；恢复时验证已知目录或失败关闭。
5. 撤销重建日志记录的目录，并更新源目录身份；跨批次引用同一已清理目录的日志也更新身份。
6. 页面默认展示类型建议，清楚说明不提取普通文件、确认后才移动及空目录清理；更新测试及说明。
7. npm run check、npm test、npm run test:e2e；独立审查安全和恢复。
